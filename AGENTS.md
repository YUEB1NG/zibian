# Project conventions

- The canonical project name is `zibian` (one word, lowercase). Use it in repository URLs, package names, new filenames and documentation. The Chinese display name is 字变.
- Keep Chinese README.md and English README.en.md equivalent when changing features or setup instructions.
- Preserve approved geometry and viewer interaction unless a change explicitly requests them.
- Keep MIT source and OFL font licensing distinct. Never bundle Tahoma glyph data in this open-source edition.
- Do not blindly rewrite historical external service URLs or unrelated upstream attribution.
