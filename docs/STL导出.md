# STL 导出

在文字编辑页，价格上方点击「导出 STL」。文字有修改时会先生成新模型，再保存对应文件；输入不合法或生成失败时不会下载旧模型。预览与导出使用同一个二进制缓冲区。

文件名形如 `zibian_LOVE_HOME.stl`。为兼容文件系统，`&` 转为 `AND`，`/` 转为 `SLASH`。

## 打印尺寸

采用二进制 STL，坐标按毫米生成，底座底面 Z=0。STL 格式本身不保存单位，切片器导入时请选择毫米。预览里的缩小 10%、旋转、拖动和放大不改变导出的实物尺寸。底座为原算法完整矩形，不做裁切。

STL 不保存颜色、纹理和打印配置。浏览器导出后用 Bambu Studio 等切片器打开，确认尺寸、连接、朝向与支撑再切片。网页报告分离笔画时，需要实际检查；封闭网格不代表所有文字组合都能直接可靠打印。

LOVE / HOME 开源 Arimo 版浏览器导出约 140.33 × 142.86 × 32.80 mm。这来自实测网格包围盒，不是预览截图比例。

## 验证边界

自动化覆盖桌面及 393/320 px 手机视口、二进制 STL 完整性、预览与下载字节一致性、修改文字后导出、旋转不改变文件、特殊字符文件名、错误输入和引擎失败不下载旧文件。网格检查见 `stl-mesh-checks.json`。

尚未进行 iPhone Safari / 安卓真机保存文件及实际打印验证。手机可能展示系统文件预览或分享入口，以浏览器的保存界面为准。

开源版将字形向底座嵌入 0.2 mm，避免圆弧底部只有相切点。原体验版的 Tahoma 网格尺寸不同。
